Godot UI sound effects, as WAV

Menus feel cheap when they are silent. These twelve clicks are short enough to fire on a Button without stacking.

Original sine tones, 44.1 kHz WAV. Godot imports WAV natively. Pay $0 for the zip.

Hook a click in Godot 4

  1. Download the free pack. Import click_primary.wav into res://sfx/.
  2. Add an AudioStreamPlayer. Set Stream to that WAV. Bus: Master or a UI bus.
  3. Connect the Button pressed signal:

$Click.play()

If the player can mash, call stop() then play(), or use a one-shot player. These files are under 150 ms, so overlap is rare.

Which file where

  • Menu button → click_primary.wav
  • Back / cancel → click_secondary.wav
  • Toggle → toggle_on.wav / toggle_off.wav
  • Save / ok → success.wav
  • Blocked action → error.wav
