Hook a click in Unity

  1. Download the free pack. Drop click_primary.wav into Assets/Audio/.
  2. On the Inspector for that clip: Load Type = Decompress On Load. These files are tiny.
  3. Add an AudioSource on the Canvas (or a UI audio object). Uncheck Play On Awake.
  4. On the Button’s On Click (), call a one-shot:
public AudioSource ui;
public AudioClip click;

public void OnPressed() {
    ui.PlayOneShot(click);
}

Use PlayOneShot, not Play(), so a mash does not cut the last click. Files are under 150 ms, so overlap is rare.

Which file where

  • Menu button → click_primary.wav
  • Back / cancel → click_secondary.wav
  • Toggle → toggle_on.wav / toggle_off.wav
  • Save / ok → success.wav
  • Blocked action → error.wav
